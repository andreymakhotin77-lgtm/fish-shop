Панель продавца

Вход для продавца

Введите значение ADMIN_TOKEN из настроек Render.

Панель не записывает ключ в локальное хранилище. После обновления страницы войдите снова.

Товары и цены сохраняются в базе магазина. Чтобы увидеть изменения в приложении, обновите его каталог.

Каталог магазина

Новый товар

Цена за 1 кг, 1 штуку или 1 упаковку. Вводится в целых рублях.

Фотография товара

Фотография пока не выбрана.

JPG, PNG или WEBP, не более 5 МБ. Загружайте только фотографии, которые можно публиковать.

Можно также вставить готовую прямую HTTPS-ссылку. После загрузки фотографии обязательно нажмите «Сохранить товар».

Если снять отметку, товар исчезнет из доступного покупателям каталога.

Заказы покупателей

Здесь находятся заказы, сохранённые в базе магазина. Суммы показываются с копейками. Статусы пока доступны только продавцу. После изменения статуса покупателю нужно сообщить о нём отдельно.

Используйте ADMIN_TOKEN из настроек Render. Ключ не сохраняется в хранилище браузера. После обновления страницы войдите заново.

Новый товар

Выберите подходящую группу. Прежняя категория существующего товара сохраняется, пока вы сами не выберете другую и не сохраните товар.

Для акции укажите реальную прежнюю цену выше текущей. Чтобы убрать акцию, очистите старую цену.

JPG, PNG или WEBP, до 5 МБ. Сначала загрузите фото, затем сохраните товар.

Снимите отметку, чтобы скрыть товар из каталога.

Ассортимент

Фильтр меняет только список в панели продавца. Он не скрывает товары от покупателей.

Заказы

Расписание получения

Московское время, UTC+3.

Доставка и самовывоз настраиваются отдельно.

Интервалы создаются на конкретную дату: на сегодня и ближайшие 60 дней. Один интервал может выбрать несколько покупателей.

Изменение или закрытие интервала не переносит старые заказы. Согласуйте изменения с покупателями отдельно. Для других городов возможность доставки согласуется отдельно.

Сервер не сообщил о поддержке расписания.

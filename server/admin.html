Панель продавца

Вход для продавца

Введите значение ADMIN_TOKEN, которое вы сохранили в настройках Render.

Панель не сохраняет ключ в локальное хранилище браузера. После обновления страницы потребуется войти снова.

Изменения сохраняются в базе магазина. Установленная старая версия Android-приложения пока не загружает каталог из базы. Подключим её следующим этапом.

Каталог магазина

Новый товар

Пока поддерживается прямая HTTPS-ссылка на изображение. Загрузка фото с телефона ещё не добавлена. Поле можно оставить пустым.

Чтобы временно убрать товар из нового каталога, снимите отметку «Товар в наличии».

Заказы покупателей

Здесь видны заказы, сохранённые после подключения базы. Старые заказы из Telegram автоматически сюда не переносятся. Статусы пока доступны только продавцу.
